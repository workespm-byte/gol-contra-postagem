Política de Privacidade

Última atualização: 12 de novembro de 2026

1. Quem somos

O Gol Contra Postagem é uma ferramenta interna e privada operada por Pedro Tostes Amaral (Niterói, Brasil), usada apenas para publicar os vídeos dele nos canais do YouTube Gol Contra e Parallax View e na conta do Instagram @golcontraoficial. Contato: phillmamaco@gmail.com.

2. Serviços de API do YouTube e terceiros

Esta ferramenta usa os Serviços de API do YouTube e a API do Instagram (Meta). Ao autorizá-la, você também concorda com os Termos de Serviço do YouTube, e seus dados também ficam sujeitos à Política de Privacidade do Google (http://www.google.com/policies/privacy) e à Política de Privacidade do Instagram.

3. Quais dados acessamos

Com a autorização do dono do canal (OAuth 2.0), a ferramenta usa somente estas permissões:

  • youtube.upload: enviar os vídeos do dono para o canal do dono e definir título, descrição, tags, categoria, idioma, privacidade e horário de publicação.
  • youtube.force-ssl: definir a miniatura, enviar a legenda (.srt) e publicar um comentário no próprio vídeo recém-publicado. Também lê o nome do canal autorizado, para confirmar que o envio vai para o canal certo.
  • Instagram: perfil básico da conta profissional do dono, publicar Reels e comentar neles.

A ferramenta não lê inscritos, espectadores, comentários de outras pessoas, estatísticas nem dados pessoais de outros usuários, e não gera métricas a partir de dados do YouTube.

4. Como usamos e guardamos os dados

  • Os dados são usados apenas para enviar e programar o conteúdo do próprio dono.
  • Os tokens de acesso ficam guardados só no computador pessoal do dono, na pasta da ferramenta, e nunca são compartilhados.
  • O único dado da API do YouTube guardado é um registro local do que foi enviado (ID do vídeo, link, horário e status), mantido enquanto a ferramenta estiver em uso.
  • Nenhum dado é vendido, alugado ou compartilhado com terceiros, nem usado para publicidade.

5. Como revogar o acesso

  • Google/YouTube: a qualquer momento em https://security.google.com/settings/security/permissions.
  • Instagram: em Configurações → Apps e sites, no app do Instagram.

6. Exclusão de dados

Quando o acesso é revogado, ou a pedido para phillmamaco@gmail.com, os tokens e registros são apagados em até 7 dias. Os dados da API do YouTube são apagados ou atualizados em no máximo 30 dias, como exigem as Políticas para Desenvolvedores dos Serviços de API do YouTube.

7. Alterações

Esta política pode ser atualizada. A data no topo indica a última versão.
