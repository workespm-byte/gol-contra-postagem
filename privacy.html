Privacy Policy

Last updated: November 12, 2026

1. Who we are

Gol Contra Postagem is a private, internal tool operated by Pedro Tostes Amaral (Niterói, Brazil) and used only to publish his own videos on the Gol Contra and Parallax View YouTube channels and on the @golcontraoficial Instagram account. Contact: phillmamaco@gmail.com.

2. YouTube API Services and third parties

This application uses YouTube API Services and the Instagram API (Meta). By authorizing it, you also agree to the YouTube Terms of Service, and your data is also subject to the Google Privacy Policy (http://www.google.com/policies/privacy) and the Instagram Privacy Policy.

3. What data we access

With the channel owner's authorization (OAuth 2.0), the tool uses only these permissions:

  • youtube.upload: upload the owner's videos to the owner's channel and set title, description, tags, category, language, privacy status and scheduled publish time.
  • youtube.force-ssl: set the custom thumbnail, upload the caption file (.srt) and post one comment on the owner's own newly published video. It is also used to read the name of the authorized channel, to confirm the upload goes to the right channel.
  • Instagram: basic profile of the owner's professional account, publish Reels and post a comment on them.

The tool does not read subscribers, viewers, comments from other people, analytics or any personal data of other users, and it does not create metrics from YouTube data.

4. How data is used and stored

  • Data is used only to upload and schedule the owner's own content.
  • OAuth tokens are stored only on the owner's personal computer, in the tool's folder, and are never shared with anyone.
  • The only YouTube API Data stored is a local log of what was uploaded (video ID, link, scheduled time and status), kept while the tool is in use.
  • No data is sold, rented, shared with or disclosed to third parties. No data is used for advertising.

5. How to revoke access

  • Google/YouTube: at any time on the Google security settings page: https://security.google.com/settings/security/permissions.
  • Instagram: Settings → Apps and websites, in the Instagram app.

6. Data deletion

When access is revoked, or on request to phillmamaco@gmail.com, the stored tokens and logs are deleted within 7 days. YouTube API Data is deleted or refreshed within 30 days at most, as required by the YouTube API Services Developer Policies.

7. Changes

This policy may be updated. The date at the top shows the latest version.
